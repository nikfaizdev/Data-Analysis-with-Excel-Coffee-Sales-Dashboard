# Coffee-Shop-Sales-Data-Analysis (Interactive Dashboard using MS Excel)
## Project Objective
This project involves the development of an Excel dashboard to analyze coffee sales data obtained from Maven Analytics. The goal is to uncover key business insights related to customer purchasing behavior, peak sales periods, and product performance. Through data visualization and trend analysis, this dashboard provides actionable insights for stakeholders.
